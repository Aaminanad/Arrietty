## ARRIETTY 

My first 3D game made in Godot 4. It is a fun project based on "The Secret World of Arrietty"


 Arrietty, a very tiny girl in a very BIG world. She collects giant sugar cubes and the more she collects the bigger she gets!

# Game play 
Main menu with a Play button
A kitchen world
Arrietty can walk around (still fixing bugs)
Sugar cubes (still fixing bugs)

# How to play
WASD = move
Mouse = camera
Space = jump
Esc = free the mouse
# How to run
Play in itch

OR:
Install Godot 4
Open the project
Press F5
