# ARRIETTY 

My first 3D game made in Godot 4. It is a fun project based on "The Secret World of Arrietty"
Arrietty is a very tiny girl in a very BIG world. She collects giant sugar cubes and the more she collects the bigger she gets!

## Game play 
1.Main menu with a Play button
2. kitchen world
3.Arrietty can walk around (still fixing bugs)
4.Sugar cubes (still fixing bugs)

## How to play
1.WASD = move
2.Mouse = camera
3.Space = jump
4.Esc = free the mouse
